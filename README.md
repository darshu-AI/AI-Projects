# AI Projects 

This repository contains three basic AI/ML projects developed as part of the PEP selection process.

Each project is organized in a separate folder with its own code, dataset, and README file explaining the implementation.

## Projects Included

### 1. Student Performance Prediction
📁 Folder: `project1_student_performance`  
Predicts a student’s final exam score using machine learning based on academic inputs.

### 2. Student Attention Detection (CNN)
📁 Folder: `project2_attention_cnn`  
Classifies student attention states using a Convolutional Neural Network.

### 3. Answer Evaluation System
📁 Folder: `project3_answer_eval`  
Evaluates student answers using NLP techniques and semantic similarity.

## Note
- All projects are kept public.
- Trained model files are excluded using `.gitignore`.
- Detailed explanations and run instructions are provided inside each project folder.

## Project Ownership
All three projects in this repository were developed individually as part of the PEP assessment.
